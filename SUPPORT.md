# Support

Use the GitHub issue tracker for bug reports and feature requests:

https://github.com/rtmo0/vscode-mongo-compass/issues

Before opening an issue, include:

- Extension version.
- VS Code version and operating system.
- MongoDB deployment type and server version.
- Reproduction steps and relevant output from **MongoDB: Show Output Channel**.

Never publish passwords, access tokens, certificates, private keys, or unredacted MongoDB connection strings.
